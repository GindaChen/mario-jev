What this run means
Order and continuity
A continuous run preserves the game between stages. If a failure loads a separate stage environment, the page changes to “Linked stages.” A full route with resets is not an uninterrupted clear. The emulator automatically advances non-playable transitions and cutscenes.
Every retry is visible
Stage restarts and checkpoint reloads are separate counters. Stage tiles show attempts and retries. Historical individual-stage wins are available in the research view and do not count toward this campaign.
Live evidence
Clears reflect completion events recorded by the runner. The feed shows its latest update time and warns when telemetry is stale. Position x is local game state, not a percentage of the whole route.
