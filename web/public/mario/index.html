How this experiment works

Play. Reflect. Try again.

01 / ACTDJev chooses the buttons

A structured observation describes Mario and the nearby terrain. DJev selects an action; the emulator advances.

02 / REFLECTFailures become lessons

System2 inspects trajectories between batches and authors stage-specific prompts. The policy can use these lessons on the next attempt.

03 / VERIFYKeep the evidence

Fresh attempts log actions, results, and prompt identity. A first clear earns a replay. Reliability requires separate frozen validation.

What the results do—and do not—establish
  • Each stage starts separately. This is not a continuous full-game clear.
  • Stage-specific guidance is allowed. Model weights are unchanged.

World1-2: 4/60 discovery wins; 20/20 frozen validation; 0/10 without the waiting lesson; 0/10 without all stage lessons. These use the same level and reset scenario.
